# arXiv subject codes

Common feed codes for `--subjects`. Full taxonomy: https://arxiv.org/category_taxonomy

A feed can also be a whole archive (`cs`, `stat`) — much larger, rarely what
you want.

## Picking subjects from a topic

When the user names only a topic, pick 1–3 likely codes, tell them which you
chose, and adjust on feedback. Rules of thumb for this vault's interests:
misinformation / social media → cs.SI + cs.CY (+ physics.soc-ph);
LLMs / NLP → cs.CL (+ cs.LG); agents → cs.MA + cs.AI;
human–AI interaction → cs.HC + cs.CY.
